الخدمات

تيار خفيف، شبكات، ومواقع وتطبيقات تحت سقف واحد

القائمة اللي تحت هي نقطة بداية مش سقف. لو عندك مشكلة تقنية أو فكرة مش موجودة هنا بالظبط — كاميرا، شبكة، موقع، تطبيق، أو نظام داخلي مخصص — قولّي عليها وهنشوف الحل مع بعض.

كاميرات المراقبة CCTV

تركيب وصيانة كاميرات IP وأنالوج، أنظمة DVR/NVR، بماركات Hikvision وDahua، مع مراقبة عن بُعد.

شبكات وجدران حماية

تصميم وإعداد جدران حماية FortiGate وCisco، تقسيم VLAN، ونشر بنية شبكية عبر فروع متعددة.

تحكم الدخول Access Control

أنظمة بصمة، بطاقات، وقفل إلكتروني للأبواب والبوابات، مرتبطة بسجلات حضور ودخول دقيقة.

إنتركم وPBX / VoIP

تركيب أنظمة إنتركم فيديو وصوت، وسنترالات PBX/VoIP للمنشآت والمجمعات السكنية.

أنظمة المنازل والمكاتب الذكية

تركيب حلول Aqara وأجهزة إنترنت الأشياء للتحكم بالإضاءة والتكييف والأمان عن بُعد.

مواقع، تطبيقات، ومنصات SaaS

أي فكرة موقع أو تطبيق أو نظام إدارة عندك — بابنيها بـ React وNext.js مع Firebase وSupabase، من الفكرة الأولى لحد التشغيل الفعلي.
